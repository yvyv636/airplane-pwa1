# Jet Rond · 圆滚滚喷气机

一台住在纯白摄影棚里的圆滚滚喷气机。实时 3D、三渲二赛璐璐着色、真实投影、可转向和加速，并带有五种涂装与夜间自动亮灯。

## 直接体验

双击 **`round-jet-app.html`** 即可。单文件、离线、无需安装或启动服务器。

## 安装为手机 App（PWA）

`jet-app/` 是一个可安装的 PWA 目录；同内容的可部署压缩包是 **`jet-rond-pwa.zip`**，解压后直接部署其中的文件即可。

- `index.html` — 应用页面
- `manifest.webmanifest` — App 名称、图标、启动方式
- `sw.js` — 离线缓存
- `icons/` — App 图标

在电脑上预览或安装：

```powershell
python -m http.server 8080 --directory jet-app
```

然后打开 `http://127.0.0.1:8080`。若要装到手机上，把 `jet-app/` 部署到任意 **HTTPS** 静态站点（GitHub Pages、Netlify、Vercel 等），在手机浏览器里选择“添加到主屏幕 / 安装应用”。iOS 需要 Safari 的“添加到主屏幕”。

## 操作

**触屏**

- 左下方 `左 / 右`：按住转向
- 右下方 `− / +`：按住减速 / 加速
- 拖动画面：环视飞机，双指缩放
- 右上角：切换视角、自动环绕、更换涂装、日间 / 夜间模式
- 双击画面：复位到 3/4 视角

**键盘**

- `W / S`：加速 / 减速
- `A / D`：左转 / 右转
- `1 2 3 4`：切换视角
- `空格`：自动环绕
- `N`：日间 / 夜间
- `C`：循环切换视角
- `R`：复位视角

## 功能

- **纯白无边际摄影棚**：日间背景与地面均为纯白，只留下飞机投影。
- **真实投影**：VSM 阴影随飞机的姿态、侧斜与位置实时变化。
- **飞行手感**：油门、转向、惯性加速；转弯时飞机按真实方向侧倾，并带轻微俯仰。
- **明显尾迹**：双发动机留下柔和烟雾轨迹，夜间呈暖色。
- **五种涂装**：奶油珊瑚、薄荷汽水、樱花苏打、柠檬奶油、雾霾蓝。
- **夜间模式**：机身自动亮起航行灯、频闪灯、尾灯、座舱灯、着陆灯与地面光池。
- **PWA**：可安装到主屏幕，支持离线打开。
- 涂装与日/夜模式会自动记住。
